# QH-V2-002 - Deterministic Evidence Collector

## Status

`APPROVED - READY FOR IMPLEMENTATION`

## Goal

Qwen의 검증 주장에 의존하지 않고,
Git과 Python으로 Task 수행 결과의 객관적인 Evidence를 수집한다.

## Problem

Qwen Worker는 실제로 확인하지 않은 파일도
"검증했다", "변경되지 않았다"고 보고할 수 있다.

파일 변경 여부와 Task Scope 준수 여부는
LLM이 아니라 deterministic code가 확인한다.

## Scope

작은 Python Evidence Collector를 구현한다.

입력:

- Repository root
- Task file path

수집할 Evidence:

1. Task의 `Allowed Changes`
2. Task의 `Forbidden Changes`
3. Git HEAD 대비 실제 changed files
4. Scope violation

출력:

- JSON 형식 Evidence

## Example

TASK:

```text
Allowed Changes:
- target.txt

Forbidden Changes:
- protected-a.txt
- protected-b.txt
