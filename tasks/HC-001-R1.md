# HC-001-R1 - Task Contract Parser Regression Repair

## Status

APPROVED - READY FOR CONTRACT BASELINE PREPARATION

## Problem

HC-001's implementation candidate passed the existing `tests/test_harness_core.py` suite but failed an additional Acceptance Criteria check.

Observed failing bullet:

    -   `src/app.py`   

The contract requires outer whitespace to be trimmed before removing one matching pair of surrounding backticks. The existing test suite did not cover that combined case.

HC-001 was not completed and the Repository was restored to a clean baseline.

## Goal

Close the HC-001 verification gap before implementation by adding a regression test for outer-whitespace-plus-backticks, then implement `parse_change_scope()` so the full Task contract is satisfied.

## Contract Clarification

For each collected `- ` bullet value:

1. remove the `- ` marker;
2. trim outer whitespace from the remaining bullet value;
3. if the trimmed value begins and ends with one matching backtick, remove exactly that outer backtick pair;
4. otherwise preserve the trimmed value exactly;
5. preserve bullet order.

Example input bullet:

    -   `src/app.py`   

Expected parsed value:

    src/app.py

## Scope

This revision is limited to the HC-001 parser contract and its missing regression coverage.

Do not implement:

- path matching;
- Git commands;
- changed-file detection;
- JSON output;
- verification command execution;
- file I/O;
- CLI behavior;
- HC-002 or later Harness Core behavior.

## Contract Baseline Preparation

Before Worker execution, the regression test must be added to `tests/test_harness_core.py` and committed together with this Task specification.

The regression test must prove that both Allowed Changes and Forbidden Changes correctly parse bullet values that have outer whitespace around a backtick-wrapped value.

The Worker must not modify the committed test.

## Acceptance Criteria

- The committed regression test covers outer whitespace around backtick-wrapped bullet values.
- `parse_change_scope()` satisfies the original HC-001 Input / Output Contract.
- Outer whitespace is trimmed before the optional surrounding-backtick removal.
- Exactly one matching outer backtick pair is removed when present.
- Unquoted bullet values remain preserved after outer whitespace trimming.
- Bullet order is preserved.
- Missing or empty required sections fail closed with `ValueError`.
- `ChangeScope` remains a frozen dataclass with `allowed` and `forbidden` tuple fields.
- No third-party dependency is added.
- During Worker execution, only `tools/harness_core.py` is modified.
- All `tests/test_harness_core.py` tests pass.
