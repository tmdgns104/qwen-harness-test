# HC-001 - Task Contract Parser

## Status

APPROVED - READY FOR IMPLEMENTATION

## Goal

Implement the pure Markdown parser used by the deterministic Harness Core.

The parser extracts only the Task change-scope contract.

## Input / Output Contract

Implement:

`parse_change_scope(markdown: str) -> ChangeScope`

in `tools/harness_core.py`.

`ChangeScope` already exists and must not be renamed or structurally changed.

The parser must:

- find the exact level-two heading `## Allowed Changes`;
- find the exact level-two heading `## Forbidden Changes`;
- collect `- ` bullet values only within each section;
- stop collecting when the next level-two `## ` heading begins;
- remove one matching pair of surrounding backticks from a bullet value;
- otherwise preserve each bullet value exactly after trimming outer whitespace;
- preserve bullet order;
- raise `ValueError` if either required section is missing;
- raise `ValueError` if either required section contains no bullet values.

## Scope

This Task implements parsing only.

Do not implement:

- path matching;
- Git commands;
- changed-file detection;
- JSON output;
- verification command execution;
- file I/O;
- CLI behavior.

## Allowed Changes

- `tools/harness_core.py`

## Forbidden Changes

- `tests/**`
- `tasks/**`
- `PROJECT.md`
- `REQUIREMENTS.md`
- `DECISIONS.md`
- `STATUS.md`
- all other Repository files

## Acceptance Criteria

- `parse_change_scope()` satisfies the Input / Output Contract.
- Missing or empty required sections fail closed with `ValueError`.
- `ChangeScope` remains a frozen dataclass with `allowed` and `forbidden` tuple fields.
- No third-party dependency is added.
- Only `tools/harness_core.py` is modified by the Worker.
- All `tests/test_harness_core.py` tests pass.
