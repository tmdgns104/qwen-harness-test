# QH-V2-002A - Parse Task Change Contract

## Status

`APPROVED - READY FOR IMPLEMENTATION`

## Goal

Task Markdown에서 Allowed Changes와 Forbidden Changes만 읽는
작은 parser를 구현한다.

## Scope

다음 함수 하나를 구현한다.

`parse_change_contract(task_path)`

반환할 정보:

- allowed_changes
- forbidden_changes
- errors

## Required Behavior

다음 Section의 bullet path만 읽는다.

- `## Allowed Changes`
- `## Forbidden Changes`

예:

Allowed Changes:

- `target.txt`
- `src/**`

Forbidden Changes:

- `protected-a.txt`
- `tests/**`

다른 Section의 bullet은 포함하지 않는다.

Task file이 없으면 예외로 종료하지 말고
`errors`에 기록한다.

## Allowed Changes

- `tools/evidence_collector.py`

## Forbidden Changes

- 다른 Harness 파일
- 기존 Task 파일
- Personal Engineering Brain Repository

## Acceptance Criteria

- Allowed Changes를 정확히 추출한다.
- Forbidden Changes를 정확히 추출한다.
- 다른 Section의 bullet은 무시한다.
- Task file이 없으면 errors를 반환한다.
- Git 기능은 구현하지 않는다.
- path matching은 구현하지 않는다.
- JSON 출력은 구현하지 않는다.
- third-party dependency를 추가하지 않는다.

## Verification

구현 후 Python으로 다음을 직접 확인한다.

- `tasks/TASK-004.md`를 읽을 수 있다.
- `target.txt`가 Allowed Changes에 포함된다.
- `protected-a.txt`와 `protected-b.txt`가 Forbidden Changes에 포함된다.

## Stop Condition

Parser 구현과 위 확인 후 즉시 중단한다.

다른 Evidence Collector 기능을 구현하지 않는다.
